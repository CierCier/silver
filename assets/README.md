# Silver logo

The mark is a silver billet with a swallow stamped into it and 47, the atomic
number of silver, in the corner. The wordmark is "SIlVER". Everything outside
the billet is transparent.

| File | Use |
| --- | --- |
| `svg/billet-color.svg` | Main mark, full colour |
| `svg/billet-{ink,black,white}.svg` | One-colour mark |
| `svg/icon-color.svg`, `svg/icon-tile.svg` | Small icons (no 47, heavier stroke) for 16–48 px |
| `svg/bird-{ink,black,white,silver}.svg` | The bird on its own |
| `svg/bird-{ink,white}-small.svg` | The bird on its own, heavier stroke for 16–48 px |
| `svg/wordmark-{ink,black,white,silver}.svg` | Wordmark |
| `svg/wordmark-plain-*.svg` | Wordmark in plain capitals, "SILVER" |
| `svg/lockup-{light,dark,black,white}.svg` | Mark and wordmark side by side |
| `svg/lockup-stacked-*.svg` | Mark above the wordmark |
| `svg/lockup-plain-{light,dark}.svg` | Side-by-side lockup with the plain wordmark |
| `png/` | PNG renders of the SVGs, at 16 to 1024 px, or at @2x and @4x for lockups |
| `favicon.ico` | 16, 32 and 48 px |

`light` and `ink` files are for light backgrounds. `dark` and `silver` files
are for dark backgrounds.

Colours: ink `#1B2130`, silver gradient `#F4F6F9` → `#CBD0D8` → `#A3AAB7`, and
stamp grey `#5A6272`.
